# Автокадр

Мобильный сайт для продажи машины: помогает снять её для объявления по шагам, привести фото к единому виду и подготовить текст.

Сайт: https://turbopash.github.io/avtokadr/

- Съёмка по списку ракурсов с подсказками и силуэтом машины.
- Редактор фото: единый цвет для всей серии, обложка, скрытие госномера.
- Данные о машине и отметки продавца для текста объявления.

Один файл `index.html`, без сборки. Данные о машине хранятся только в браузере.

## Ограничения

Страница сделана как артефакт Claude. Автопоиск номера, генерация текста и кнопка сохранения работают только внутри claude.ai. На GitHub Pages номер отмечается вручную, а готовое фото сохраняется долгим нажатием на него в редакторе.
